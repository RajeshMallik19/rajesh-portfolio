# Rajesh Malick portfolio (v4, "canvas" design)

Static site. Upload `index.html` and the whole `assets/` folder to the repo root (RajeshMallik19/rajesh-portfolio). Vercel redeploys on its own.

Pages: home, Zuper Connect, Experience audit, Job Chat, Kern, Telemed Connect, Omni Fashion, FOOZ.

Fonts load from Google Fonts (Bricolage Grotesque, Instrument Sans, JetBrains Mono, Caveat), so an internet connection is needed for the intended look.
To replace an image, overwrite the file in `assets/` with the same name (webp).

Two sentences are intentionally left out until you write them:
- Audit page, Review section: which findings became tickets or were fixed.
- Job Chat page, Result section: what you would do differently.
